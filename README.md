# Lobby Character Inspect

A lightweight, 100% client-side Quality-of-Life mod that allows you to rotate and inspect survivor models in the character selection screen.

## Features

* **Smooth Drag Rotation:** Left-click anywhere on the screen and drag your mouse to spin the survivor pedestals.
* **Inertia & Momentum:** Releasing the drag applies smooth physics, letting the characters finish spinning with a satisfying deceleration drift.
* **Instant Angle Reset:** Right-click anywhere on the screen to instantly snap all characters back to their default forward-facing position.
* **Multiplayer Support:** Works in online lobbies! You can rotate and view your friends' selected survivors on your screen without affecting their view.
* **Vanilla Safe:** Since it runs entirely client-side, you can join vanilla lobbies or play with friends who don't have the mod installed. It will never cause "Version Mismatch" errors.

## Compatibility

This mod was engineered to hook into the core platform render layers of the game rather than the user interface layout. As a result, it is highly robust and fully compatible with popular lobby modifications, including:
* **ScrollableLobbyUI** (by KingEnderBrine)
* **LobbySkinsFix** (by KingEnderBrine)
* **DynamicSkinsFix** (by mwmw)

## Installation

### Via Mod Manager (Recommended)
1. Open **r2modman** or the **Thunderstore Mod Manager**.
2. Search for `Lobby Character Inspect` and click **Install**.
3. Launch the game modded!

### Manual Installation
1. Ensure you have **BepInEx** installed.
2. Download the mod archive and extract the compiled `.dll` file.
3. Drop the file directly into your game folder path:  
   `Risk of Rain 2/BepInEx/plugins/`
